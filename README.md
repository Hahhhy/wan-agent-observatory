# Wan 视频生成实验对照

分享地址：https://hahhhy.github.io/wan-agent-observatory/

打开 index.html 也可离线查看。页面无需密钥、GPU或在线模型。

- 共43条视频记录、193条公开研究调用记录，包含搭档五步/baseline、原十步实验、同前缀候选和新十条共享链。记录数不等于独立视频内容数或成功调用数。
- 每条视频左侧播放、右侧展示完整生成prompt、seed、九项指标、对应本批baseline及逐项差值。没有匹配baseline时明确标注，不跨版本拼接改善幅度。
- 旁边的Agent输入区可按实际接入步骤切换，展示任务prompt是否真的发送、状态、Attention/候选Probe、论文背景、视频内历史、跨视频经验、图像输入情况，并提供原system和完整实际请求。
- 同处查看该步骤的动作、公开理由、预期效果、API耗时和Token；保留真实访谈、8帧视觉反馈、参数轨迹和多组指标CSV。
- 原始MP4保持原SHA；额外WebM只用于浏览器兼容。各批评分独立保留。R071仅改变展示，不发起GPU或模型请求。

原50步实验的五步与十步除接入频率，还存在提示、输入和代码版本差异，不能当作严格频率消融。本轮十条共享采用12步快速实践，20次动作均保持α=0.9，缺少reset配对，尚未证明共享带来质量收益。保留负结果，不把模型公开回答称作隐藏思维链。

公开数据在data.json，原构建记录在BUILD.json，展示更新和数据/媒体不变证明在VIDEO_DETAILS_UPDATE.json。此展示库不包含模型权重、API凭据或服务器访问凭据。
