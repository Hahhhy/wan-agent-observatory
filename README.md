分享：https://hahhhy.github.io/wan-agent-observatory/

R072按三个实验问题组织：

1. 早期十步／中性十步结果与输入 → 全部访谈 → 访谈后新增输入及system原文 → 新共享版视频／指标 → 结论。明确A/B/C三版身份，不把不同任务、步数的版本变化当作单独提示词效果。
2. 十条共享：十段可播放视频、全部九项指标、真实0–9经验数、生成／Agent／观测／VideoScore内部／反馈API／其余流程计时、实际输入、两次决策与8帧成片反思。无reset配对不填改善值。
3. 五步／十步：各自批次baseline与Agent视频、九项原值及各自delta、实际α轨迹、逐步完整公开回答、prompt/input/环境差异。十步可切中性版与早期探索版，后者缺同批baseline时明确留空。
